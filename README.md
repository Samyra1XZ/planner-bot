# Planner Bot

Личный Telegram-бот для планирования задач с напоминаниями.

## Возможности

- Свободный ввод: просто напиши "встреча в 15:00" или "позвонить маме через 2 часа"
- Голосовые сообщения — бот распознаёт речь через Groq (Whisper-large-v3-turbo) и создаёт задачу
- Двойное напоминание: за 10 минут и в точное время
- Команды: `/add`, `/list`, `/done`

## Установка

### 1. Клонируй репозиторий

```bash
git clone https://github.com/Samyra1XZ/planner-bot.git
cd planner-bot
```

### 2. Установи зависимости

```bash
pip install -r requirements.txt
```

### 3. Получи бесплатный API-ключ Groq (для голоса)

Зарегистрируйся на https://console.groq.com и создай API-ключ в разделе **API Keys**.
Бесплатного лимита с запасом хватает для личного использования. Ключ — в `.env` (см. ниже).

### 4. Создай файл `.env`

```bash
cp .env.example .env
```

Заполни значения:
```
BOT_TOKEN=токен_от_BotFather
MY_CHAT_ID=твой_chat_id
GROQ_API_KEY=ключ_от_console.groq.com
STT_PROVIDER=groq
```

Узнать свой chat_id: напиши боту `@userinfobot` в Telegram.

### 5. Запусти бота

```bash
python bot.py
```

## Распознавание голоса — сменный движок

Движок задаётся переменной `STT_PROVIDER` в `.env`:

| Значение | Где работает | Приватность | Что нужно |
|----------|--------------|-------------|-----------|
| `groq` (по умолчанию) | облако Groq | аудио уходит в Groq | `GROQ_API_KEY` |
| `whisper` | локально на сервере | аудио **не покидает** хост | `ffmpeg` + `pip install openai-whisper`, переменная `WHISPER_MODEL` (по умолчанию `base`) |

Режим `whisper` нужен для клиентов с требованием конфиденциальности — переключение
не требует изменения кода, только смены переменной окружения.

## Деплой на Railway (постоянное хранилище)

Напоминания хранятся в `reminders.db`. На дефолтном Railway диск **эфемерный** —
файл сбрасывается при каждом редеплое, и все будущие задачи и дни рождения пропадут.
Чтобы данные жили, подключи постоянный диск (Volume):

1. В сервисе Railway → **New → Volume**, mount path: `/data`.
2. В **Variables** добавь: `DB_PATH=/data/reminders.db`.
3. Передеплой. Теперь база лежит на Volume и переживает любые редеплои.

Часовой пояс зашит как `Asia/Makassar` (UTC+8) в коде — серверное время Railway роли не играет.

## Использование

| Способ | Пример |
|--------|--------|
| Задача с датой | `15.06 в 10:00 оплатить аренду` |
| На завтра | `завтра в 9 утра созвон` |
| Только дата | `15 июня купить торт` (бот переспросит время) |
| День рождения | `ДР мамы 20 августа` (ежегодно, напомнит за 2 дня и в день) |
| Голосовое | отправь голосовое сообщение 🎤 |
| Список задач | `/list` |
| Дни рождения | `/birthdays` |
| Выполнить | `/done 3` |
